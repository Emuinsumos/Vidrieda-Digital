Preguntas frecuentes

¿Tengo que entender de tecnología para usarla?+
No. El panel se maneja como cualquier app: cargás una foto, un precio, y listo. Si sabés usar WhatsApp, sabés usar esto sin problemas.
¿Mis clientes tienen que descargar algo?+
No. Es una página web normal, se abre desde cualquier link o código QR, sin instalar absolutamente nada en sus teléfonos.
¿Puedo pedir cambios después de tenerla lista?+
Sí, la página se adapta a medida que tu negocio crece o cambia: nuevas categorías, nuevas herramientas, o simples ajustes de diseño.
¿Sirve para mi rubro si no es de los que mencionan?+
Sí, 100%. La base tecnológica es la misma para cualquier comercio que venda productos o servicios; lo único que cambia es cómo la acomodamos a tu forma de trabajar.
